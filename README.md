# Premier — Model Management Agency Website

A clean, editorial-style frontend for a model management agency. Built with pure HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies.

## Live Demo

> Hosted on GitHub Pages:  
> **[https://YOUR_USERNAME.github.io/premier-model-agency](https://YOUR_USERNAME.github.io/premier-model-agency)**  
> *(replace with your actual URL after deploying)*

## Features

- **Full-screen video hero** with overlay text and animated intro
- **Auto-scrolling model carousel** — infinite loop animation using pure CSS
- **Alphabetical model filter bar** — scrollable on mobile
- **Editorial two-column layout** (Page 2 & Page 3)
- **Hover-reveal portrait cards** in the Updates section
- **Marquee ticker** with outlined stroke text
- **Fully responsive** — works on desktop, tablet, and mobile phones
- **Monument Extended** display font for a luxury editorial feel
